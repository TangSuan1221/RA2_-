## 3. A 组 · 槽位系统（不变量 I2 主战场，基线 7/7）

夹具：`参考实现/verify.mjs` 内的 `simSlots()`（10 AI + 1 玩家，可注入障碍与玩家位移）。

| ID | 输入 | 断言 |
|---|---|---|
| **A1** | 平地，1 玩家静止 + 10 AI，1800 步 | 逐步 `countAttackers(table) ≤ SL-MAX-ATTACKERS(2)`，违例 = 0，且攻击次数 > 0 |
| **A2** | 玩家背靠墙（墙面 z=−1.2m） | 被挡延伸线 ≥ 5；无槽位穿入墙体（z ≤ 墙表面 = 0）；无槽位与障碍重叠 |
| **A3** | 3 根 r=0.4m 柱子（−40°/0°/+40°，距 2.0m） | 所有槽位到障碍净空 ≥ `SL-PROBE-RADIUS`；开阔地为全 0 环；有柱时 ≥1 个槽被推到外环；槽位数 ≤ 8 |
| **A4** | 1 个 AI 拿 token 后不攻击，跑 200 步 | token 在 `SL-RESERVE-TTL`(90 步) ±3 步内回收；`SL-RELEASE-COOL`(48 步) 内申请被拒；冷却后可再拿 |
| **A5** | 混战 1800 步 | 每个 AI 出手瞬间必须持有 token（背后命中也须经授予），违例 = 0 |
| **A6** | 玩家每步位移 0.08m（<0.1），120 步 | 槽位索引保持稳定，换槽次数 ≤ 2（迟滞 `SL-HYSTERESIS`） |
| **A7** | 同输入两次调用 `buildSlotTable` | 输出槽位数组哈希相同（纯函数，`03 §4.1` 契约） |

`buildSlotTable(player, obstacles, step, prev)` 必须是纯函数；token 状态只在 `createTable/updateTable/requestSlot/releaseSlot` 里。

## 10. 偏离与仲裁规则（防止走捷径）

| 情形 | 正确做法 | 错误做法 |
|---|---|---|
| 断言跑不过 | 标 `skip` 并写"未通过 + 原因 + 缺什么"，继续下一里程碑 | 改阈值/改断言/删测试 |
