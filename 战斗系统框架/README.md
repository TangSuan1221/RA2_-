## 5. 三个最容易被做错的地方（都是脚本实测出来的，不是推想）

1. **槽位不是"玩家周围 16 个固定点"**。16 是**延伸线**数；槽位是线上的**间隙**，按 4Hz 重算，被障碍挡住时要沿线改位（≤3 步 = 67.5°）。做成固定点就会得到"敌人排队站在同一批坐标上"。→ `a2`/`a3` 断言 + `09 §4`。
2. **相机收缩必须瞬时、伸长必须平滑**。两者都想用弹簧 → 贴墙抽搐 13 次/圈；两者都用硬钳制 → 离墙瞬间弹跳 0.8m。正确解是 `if (len > allowed) { len = allowed; v = 0 }`，剩下交给弹簧。→ `d1`/`d5`。
3. **冻帧是 per-actor，不是全局**。全局 `world.hitstop` 会把第三方 AI 和相机一起冻住，1v2 时表现为"世界卡住"，还会破坏回放哈希。本框架已把 03 章的 `world.hitstop` 作废，改成 `actor.combat.hitstopUntil`。→ `c6`。
