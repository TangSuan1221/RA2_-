## 核心不变量（违反任何一条即返工）

- **I1** 逻辑固定 60Hz + 渲染插值，逻辑步不受帧率影响
- **I2** 同时持有攻击 token 的 AI ≤ 2，**任何** AI 的背后命中都必须经槽位授予
- **I3** 攻击预警（tell）必须早于命中 ≥ 80ms
- **I4** 受击走独立 Additive 层，不锁死下半身（除击倒/处决）
- **I5** 核心计算纯函数化，随机只能来自传入的 seeded RNG（禁止 `Math.random` / `Date.now`）

## 证据分级

| 等级 | 含义 |
|---|---|
| **E0** | 需求（来自 GDD，必须满足） |

| **E2** | 二手转述（可信但需标注） |
| **E3** | 工程估算（必须用实验校准，见 `11` 章） |

一手依据只有三处：**GDC 2021《Melee AI in The Last of Us Part II》(Min-Lun Chou)**、**Epic 官方 Motion Matching 文档**、**timofeji/MontageGraph 的碰撞缓存机制**。
特别说明：MontageGraph 的 README **从未提及顽皮狗**（它服务于联机剑斗游戏 EonBlade），本仓库只取其「碰撞烘焙 + 对跳过帧的回溯扫掠」。
